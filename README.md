## **LISTA_COMANDOS** 

• git init: Crea un repositorio nuevo de Git en tu carpeta actual.

• git clone <url>: Descarga una copia de un repositorio existente desde internet.

• git config --global user.name "Nombre": Define tu nombre de usuario para los registros.

• git config --global user.email "correo": Define tu correo electrónico.

• git status: Muestra el estado actual de tus archivos (modificados, listos o sin seguimiento).

• git add <archivo> o git add .: Prepara los cambios seleccionados para guardarlos en la siguiente confirmación.

• git commit -m "mensaje": Guarda de forma permanente los archivos preparados en el historial local junto con una descripción.
